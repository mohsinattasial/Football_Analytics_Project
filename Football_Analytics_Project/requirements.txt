⚙️ How to Install the Libraries
Open your terminal in VS Code (make sure you are inside the Football_Analytics_Project folder) and run this command:

Bash
pip install -r requirements.txt
Short Breakdown of the Tools:

pandas & numpy: These form the core engine for loading, cleaning, filtering, and structuring your data.

matplotlib & seaborn: The best libraries for creating professional and colorful graphs (like bar charts, heatmaps, and trend lines).

jupyter: Essential for running .ipynb files in your notebooks/ folder, allowing you to view data and charts step-by-step.

rich: If you want to print aesthetic, color-coded tables or dashboards directly in your terminal (which looks highly professional), this library will handle that.
